# Checklist — Kids' Interactive Storytelling Website

Mark each item ✅ Pass / ❌ Fail / ⏭ Skip during a test run.

## Navigation & layout

- [ ] Hamburger menu is stable while scrolling
- [ ] All header links open the correct pages
- [ ] Text is readable on every page (contrast)
- [ ] Age rating badge shows the correct value on load

## Language

- [ ] Clicking the active language does nothing
- [ ] Switching GE ↔ EN translates all content
- [ ] No console errors when switching language

## Contact

- [ ] Contact info (phone, emails, social links) is complete and in one place
- [ ] Empty message cannot be sent
- [ ] Invalid email/phone formats are rejected
- [ ] Successful submission shows a confirmation

## Games (3+ audience)

- [ ] Child can continue when a task is finished early
- [ ] Sound/music controls are available during the game
- [ ] Settings panel does not cover the illustration
