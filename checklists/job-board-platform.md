# Checklist — Job Board & Community Platform

Mark each item ✅ Pass / ❌ Fail / ⏭ Skip during a test run.

## Notifications

- [ ] Each notification opens the related post
- [ ] Notifications are marked as read after opening

## Comments & blogs

- [ ] Closing a comment with text shows a clear warning
- [ ] Leaving the blog editor with unsaved text asks for confirmation

## Jobs

- [ ] Jobs can be saved and unsaved
- [ ] Saved jobs appear in the profile, sorted by date

## Admin

- [ ] Admin can block a user
- [ ] Admin can unblock a user
- [ ] Blocking rules are published for users
