# Checklist — HR / Recruitment Platform

Mark each item ✅ Pass / ❌ Fail / ⏭ Skip during a test run.

## Registration

- [ ] Duplicate email shows a clear error
- [ ] Required fields are validated
- [ ] Password rules are enforced

## Login & roles

- [ ] Candidate cannot log in as company
- [ ] Company cannot log in as candidate
- [ ] Wrong password shows an error
- [ ] Logout ends the session
