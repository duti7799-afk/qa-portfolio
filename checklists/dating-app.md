# Checklist — Dating Mobile App

Mark each item ✅ Pass / ❌ Fail / ⏭ Skip during a test run.

## UI (Android)

- [ ] Header respects the status bar / safe area on all screens
- [ ] Layout works on different screen sizes

## Preferences

- [ ] Gender and age range are saved
- [ ] Preferences persist after force-close
- [ ] Preferences persist after logout/login

## Swiping

- [ ] Like / Pass work as expected
- [ ] First-time onboarding hint is shown
- [ ] Undo/Rewind returns only the last profile (if implemented)

## Verification

- [ ] At least one face photo is required
- [ ] The only verified photo cannot be deleted
