# REC-18: Add an Undo / Rewind action for accidental swipes

| Field | Value |
|---|---|
| **Project** | Dating Mobile App |
| **Priority** | — |
| **Status** | In review |

## Current Behavior
There is no way to undo a swipe. If the user accidentally passes on or likes a profile, they cannot go back.

## Problem
Mistakes caused by fast swiping or accidental touches cannot be corrected.

## Proposed Solution
Add a rewind (circular arrow) icon on the main screen that returns only the last rated profile so the user can choose again (Like or Pass).

## Justification
More forgiving and practical UX.
