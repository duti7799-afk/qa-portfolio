# REC-16: Add a separate “Saved jobs” section to the user profile

| Field | Value |
|---|---|
| **Project** | Job Board & Community Platform |
| **Priority** | Normal |
| **Status** | Accepted |

## Current Behavior
Saved jobs are pinned to the top of the job list on the home page.

## Problem
This will not scale when dozens of jobs are added.

## Proposed Solution
Create a “Saved jobs” section on the profile page, listing saved jobs sorted by date.

## Justification
Easier to find and review saved jobs.
