# REC-14: Add an “Unblock user” action to the admin panel

| Field | Value |
|---|---|
| **Project** | Job Board & Community Platform |
| **Priority** | High |
| **Status** | Implemented |

## Current Behavior
Admins can block (ban) a user but cannot unblock them.

## Problem
A user blocked by mistake — or one whose block should end — cannot be restored.

## Proposed Solution
Add an unblock function next to the block function in the admin panel.

## Justification
Allows fixing mistakes and avoids user dissatisfaction and loss of trust.
