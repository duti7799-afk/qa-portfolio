# REC-15: Warn the user before leaving a blog post that is being written

| Field | Value |
|---|---|
| **Project** | Job Board & Community Platform |
| **Priority** | Normal |
| **Status** | Implemented |

## Current Behavior
If the user leaves the page while writing a blog post, it closes without any warning.

## Problem
Unsaved text is lost.

## Proposed Solution
Show a confirmation (“Do you really want to leave this page?” Yes / No) before leaving.

## Justification
Prevents data loss and improves UX.
