# REC-13: Make the “close comment window” message clearer

| Field | Value |
|---|---|
| **Project** | Job Board & Community Platform |
| **Priority** | Normal |
| **Status** | Implemented |

## Current Behavior
If the user types a comment and clicks Close, the window closes with a generic message that does not say what happens to the text.

## Problem
Users may be confused whether their text is lost or saved.

## Proposed Solution
Show a clear message, e.g. “Do you really want to close? Your text will not be saved.”, with two buttons: “Close” (discard) and “Continue editing”.

## Justification
Prevents accidental loss of written comments.
