# REC-12: Put all contact information in one place

| Field | Value |
|---|---|
| **Project** | Kids' Interactive Storytelling Website |
| **Priority** | Low |
| **Status** | Submitted |

## Current Behavior
Contact details (emails, phone numbers, social links) are spread over different pages.

## Problem
Users have to search several pages to find how to contact the company.

## Proposed Solution
Collect all contact details in one section — the existing hamburger menu next to the emails, or a dedicated Contacts page.

## Justification
Users see all contact channels in one place.
