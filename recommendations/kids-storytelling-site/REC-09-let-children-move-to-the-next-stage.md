# REC-09: Let children move to the next stage when they finish a task early

| Field | Value |
|---|---|
| **Project** | Kids' Interactive Storytelling Website |
| **Priority** | Normal |
| **Status** | Submitted |

## Current Behavior
If a child finishes drawing or colouring before the timer ends (e.g. 1 minute), they must wait for the timer to run out.

## Problem
For a 3+ audience, waiting can make the child lose interest.

## Proposed Solution
Option A: show a “Next” button as soon as the task is done. Option B: detect that all areas are coloured and move on automatically.

## Justification
The game becomes more dynamic and user-friendly.
