# REC-07: Replace the technical word “header” in the out-of-office message

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Status** | Submitted |

## Current Behavior
The out-of-office notice tells users to “use the button located in the header” to return to the AI chat.

## Problem
Most users do not know web terms like “header”.

## Proposed Solution
Use plain language, e.g. “use the same button you used to contact an operator”, or name the icon (“the robot icon”).

## Justification
Less confusion — customers can easily return to the AI assistant.
