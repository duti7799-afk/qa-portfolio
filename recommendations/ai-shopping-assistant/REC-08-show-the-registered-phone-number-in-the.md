# REC-08: Show the registered phone number in the operator’s profile

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Status** | Submitted |

## Current Behavior
The operator’s mobile number is not visible on their profile page.

## Problem
It is hard to find contact information and reach the operator quickly.

## Proposed Solution
Add a “Mobile number” field to the operator’s profile that shows the number used at registration.

## Justification
Faster internal communication.
