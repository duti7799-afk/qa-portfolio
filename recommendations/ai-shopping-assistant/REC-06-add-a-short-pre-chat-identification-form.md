# REC-06: Add a short pre-chat identification form

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | — |
| **Status** | Submitted |

## Current Behavior
Users can start chatting right away without giving any identifying information (first and last name).

## Problem
Support agents have to ask for basic contact details manually.

## Proposed Solution
Ask for first and last name in a short form before the conversation with the AI or an operator starts.

## Justification
Agents can identify the user immediately, which reduces handling time.
