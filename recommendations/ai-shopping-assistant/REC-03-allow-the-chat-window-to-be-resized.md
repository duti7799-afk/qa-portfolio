# REC-03: Allow the chat window to be resized and moved

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Status** | Submitted |

## Current Behavior
The chat window has a fixed size and position and covers an important part of the page (product list, prices, descriptions).

## Problem
Users cannot read the bot’s answer and compare products on the page at the same time.

## Proposed Solution
Let users drag a corner of the chat window to resize it, and move the window to any side of the screen.

## Justification
Users can read recommendations and browse products in parallel, without constantly minimising and reopening the chat.
