# REC-04: Support Excel file upload in the chatbot

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Status** | Submitted |

## Current Behavior
The chat supports text messages and PDF / Word uploads, but not Excel files with tables and numbers.

## Problem
Users have to convert Excel files to PDF/Word or paste data manually, which breaks the column/row structure and leads to misinterpreted data.

## Proposed Solution
Allow uploading Excel files directly in the chat interface.

## Justification
Less manual work, no formatting problems and more accurate processing of numeric and tabular data.
