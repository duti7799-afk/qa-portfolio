# BUG-28: Product sorting/filter (e.g. “Discount”) does not work inside a category

| Field | Value |
|---|---|
| **Project** | Fashion E-commerce Website |
| **Priority** | High |
| **Environment** | Lenovo laptop · Windows 11 Pro (build 26100) · Google Chrome 139 |
| **Reproducibility** | 100% |

## Steps to Reproduce
1. Open the website.
2. On the home page choose any category: Women / Men / Kids.
3. Choose a sorting option, e.g. “Discount”.

## Expected Result
Products are re-sorted by the chosen option and the heading shows the selected option.

## Actual Result
Nothing happens — the list stays on “Newest first”.
