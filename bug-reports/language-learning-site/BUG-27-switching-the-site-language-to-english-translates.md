# BUG-27: Switching the site language to English translates only the menu bar

| Field | Value |
|---|---|
| **Project** | Language Learning Website |
| **Priority** | High |
| **Environment** | Lenovo laptop · Windows 11 Pro (build 26100) · Google Chrome 139 |
| **Reproducibility** | 10 / 10 (100%) |

## Steps to Reproduce
1. Open the website.
2. Select English in the bottom-right corner.

## Expected Result
All text on the site is shown in English.

## Actual Result
Only the menu bar changes to English; the rest of the content stays in Georgian.

## Notes
Localization issue.
