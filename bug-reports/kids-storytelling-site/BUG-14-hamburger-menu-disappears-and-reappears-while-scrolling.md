# BUG-14: Hamburger menu disappears and reappears while scrolling

| Field | Value |
|---|---|
| **Project** | Kids' Interactive Storytelling Website |
| **Priority** | Normal |
| **Environment** | Lenovo ThinkPad laptop · Windows 11 Pro (build 26200) · Google Chrome 149 |
| **Reproducibility** | 100% |

## Steps to Reproduce
1. Open the website.
2. Open the hamburger menu.
3. Scroll down, then scroll back up.
4. Watch the menu.

## Expected Result
The menu stays stable and does not disappear while scrolling.

## Actual Result
When scrolling down, the menu disappears and then appears again.
