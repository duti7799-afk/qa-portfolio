# BUG-15: Phone number disappears from the contact information in the hamburger menu

| Field | Value |
|---|---|
| **Project** | Kids' Interactive Storytelling Website |
| **Priority** | Normal |
| **Environment** | Lenovo ThinkPad laptop · Windows 11 Pro (build 26200) · Google Chrome 149 |
| **Reproducibility** | 80% |

## Steps to Reproduce
1. Open the website.
2. Open the hamburger menu and look at the “Contact information” section.

## Expected Result
The contact phone number is always visible together with the email addresses.

## Actual Result
The phone number field disappears and is not always visible, so the user cannot see or check the number.
