# BUG-19: Contact form can be sent with an empty message

| Field | Value |
|---|---|
| **Project** | Kids' Interactive Storytelling Website |
| **Priority** | Normal |
| **Environment** | Lenovo ThinkPad laptop · Windows 11 Pro (build 26200) · Google Chrome 149 |
| **Reproducibility** | 100% |

## Preconditions
User is on the home page.

## Steps to Reproduce
1. Go to the Contact page.
2. Enter valid name, phone number and email.
3. Leave the message field empty and click “Send”.

## Expected Result
The form is not sent and a validation message asks the user to write a message.

## Actual Result
The form is sent with an empty message. A photo icon also appears next to the Send button.
