# BUG-24: No error message when registering with an email that is already registered

| Field | Value |
|---|---|
| **Project** | HR / Recruitment Platform |
| **Priority** | High |
| **Environment** | Lenovo laptop · Windows 11 Pro (build 26100) · Google Chrome 141 |
| **Reproducibility** | 100% |

## Steps to Reproduce
1. Open the website and choose “Registration”.
2. Use an email that is already registered.
3. Fill in the rest of the form.
4. Click “Create candidate account”.

## Expected Result
A clear message says the email is already in use.

## Actual Result
Registration is not completed, but no message explains which field is wrong or that the account already exists.
