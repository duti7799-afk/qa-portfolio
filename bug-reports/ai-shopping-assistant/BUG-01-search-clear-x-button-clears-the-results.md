# BUG-01: Search clear (X) button clears the results grid but leaves the query in the search field

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Environment** | Lenovo ThinkPad laptop · Windows 11 Pro (build 26200) · Google Chrome 147 |
| **Reproducibility** | 100% |

## Steps to Reproduce
1. Open the website.
2. Type any product name into the search field (e.g. “phone”).
3. Click the X button next to the search button.
4. Check the search field.

## Expected Result
Both the search results grid and the search field are cleared.

## Actual Result
Only the search results grid is cleared — the typed query stays in the search field.
