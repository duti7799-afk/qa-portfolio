# BUG-06: Clicking a quoted (replied) message in the chat does not scroll to the original message

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Environment** | Lenovo ThinkPad laptop · Windows 11 Pro (build 26200) · Google Chrome 147 |
| **Reproducibility** | 100% |

## Steps to Reproduce
1. Open the website and the chatbot.
2. Ask for help choosing a product so the bot returns a product list.
3. Use “Reply” on one of the bot’s products/messages.
4. After sending, click the quoted message header inside your own reply.

## Expected Result
The chat scrolls to the original message and briefly highlights it.

## Actual Result
Nothing happens — the chat stays where it is.
