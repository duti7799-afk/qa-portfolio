# BUG-13: Chat icon does not always show a notification when the answer arrives while the chat is minimised

| Field | Value |
|---|---|
| **Project** | AI Shopping Assistant |
| **Priority** | Normal |
| **Environment** | Lenovo ThinkPad laptop · Windows 11 Pro (build 26200) · Google Chrome 147 |
| **Reproducibility** | 2 / 5 attempts |

## Steps to Reproduce
1. Open the website and the chatbot.
2. Ask any question.
3. While the bot is still searching, minimise the chat window.
4. Watch the chat icon.

## Expected Result
When the bot finishes, the chat icon always shows a visible change (badge, animation or message).

## Actual Result
In some cases nothing changes on the chat icon after the answer is ready.

## Notes
Intermittent issue (reproduced 2 of 5 attempts).
